Why it works

AdShield runs a local, server-less VPN on your phone. It intercepts only DNS lookups and refuses the ones pointing at ad & tracker servers — so ads can't load anywhere. Nothing is proxied off your device; the rest of your traffic is untouched. Same technique as AdGuard, Blokada and DNS66.

app asks for an ad domain ─► AdShield checks its blocklist
   ├─ on the list  ─► answered "not found"  (ad never loads)
   └─ not on list  ─► forwarded normally     (everything works)

Features

🛡️

System-wide

Blocks ads in apps and browsers at the DNS level — not just one app.

🔒

No root, private

Runs a local VPN with no remote server. Your traffic never leaves the phone.

📊

Live counter

Watch blocked requests tick up in real time, right on the home screen.

🔄

Auto-updating list

Ships with a seed list, then pulls ~150k domains from StevenBlack/hosts.

Install in 4 steps

  1. Download the APK using the button above, on your Android phone.
  2. Open the downloaded file. If asked, allow install from unknown sources.
  3. Launch AdShield and flip the big switch on.
  4. Approve the one-time Android VPN consent dialog. Done — ads are blocked.

Good to know

• Can't block ads served from an app's own domain (e.g. some YouTube ads).
• Apps that hard-code their own DNS resolver can bypass it.
• Not on Google Play — ad blockers aren't allowed there, so AdShield is sideload-only.
• Open source — read the code on GitHub.
